Cited answers

Every answer shows its source

Answers quote the paper. Click a citation and the PDF jumps to the exact passage, highlighted.

What to look for

  1. The question asks for the main finding and the key evidence.
  2. Look for the small numbers after each sentence. Each one points to a passage in the paper.
  3. Clicking a number shows the exact words quoted, with the page number.
  4. The PDF then scrolls to that passage and highlights it, so you can check it yourself.
Fast details

Pull out the details in seconds

Ask for the subjects, task, recording method or session timeline and get them laid out, each with a citation.

What to look for

  1. One request asks for four things at once: the animals, the task, the recording method and the session timeline.
  2. The answer lays the timeline out as a table, showing what the mouse did at each point and which recording was made.
  3. Every point carries a citation number, so each detail can be traced back to the paper.
Compare

Compare papers side by side

Type @ to bring in any paper from your library, then ask for a comparison table with citations.

What to look for

  1. Typing @ opens a list of papers from your library.
  2. Pick the papers you want. Each one appears as a small tag in the message box.
  3. The answer is a table that lines the papers up side by side, by method and by main finding.
  4. Below the table, a short summary explains how the papers fit together, with citations.
Library chat

Ask your whole library

The agent searches and reads across all your papers, then answers with the ones that matter, cited.

What to look for

  1. Switch to Library chat to ask about all your papers at once, not just the one that is open.
  2. The question: which papers in my library argue that representational drift is useful, not just noise?
  3. The Task progress line at the top counts as it works: papers read in depth, papers found, papers cited.
  4. The answer groups the papers by kind of evidence (models, theory, animal studies), each with citations.
Task progress

See how the agent got there

Task progress keeps the whole run, including the plan, every paper it read, why each one matters, and the passage it quoted. Show in answer takes you back to the claim.

What to look for

  1. Task progress opens beside the answer and shows the whole run.
  2. Steps lists what the agent set out to check, with a tick next to each finished step.
  3. In your library lists every paper it used. Click one to see why it matters and the passage it quoted.
  4. Show in answer jumps back to the answer and highlights the sentence that paper supports.
Notes

Edit notes in place

Select text in a Zotero note to rewrite, expand or proofread it. Review the diff, then replace.

What to look for

  1. Select a paragraph in a Zotero note. A small menu offers Rewrite, Expand, Proofread or Ask in sidebar.
  2. Choose Rewrite. The change shows as a comparison: removed words in red, new words in green.
  3. Nothing changes until you decide: Replace, Insert below, or Discard.
Inline ask

Ask about any sentence

Select text in the PDF to explain, define or translate it, then save the answer as an annotation.

What to look for

  1. Select a sentence in the PDF and choose Inline Ask from the pop-up menu.
  2. Pick Explain, Define terms or Translate, or type your own question.
  3. The answer opens right next to the text, in plain language, so you never leave the page.
  4. Save as annotation keeps the answer together with the highlighted passage in Zotero.
Skills

Bring your own skills

Write a workflow once as a skill and run it with /. A journal-club brief, a methods checklist, anything you repeat.

What to look for

  1. The Skills panel holds saved workflows, such as journal-club-brief, compare-papers and analyze-figures.
  2. Type / in the message box to list every action and skill, then pick one.
  3. Here, journal-club-brief turns one short request, “Prep me for Friday’s journal club”, into a one-page brief.
  4. The brief has the same layout every time: research question, design, three figures to lead with, and limitations, all cited.
Import

Find and import related papers

Browse recommendations, references and citing papers, tick the ones you want, and import them in one step.

What to look for

  1. Type / and choose discover_related.
  2. A panel lists related papers. Switch between Recommendations, References and Citations, and sort by relevance, date or citation count.
  3. Tick the papers you want and click Import selected.
  4. The papers arrive in your Zotero library. Here, 5 are imported in one step.
Organize

Organize in plain words

Ask the agent to tag papers by topic. Every change is checked against Zotero and listed in a receipt.

What to look for

  1. In Library chat, ask in plain words: tag every paper about representational drift in olfactory or piriform cortex with “olfactory-drift”.
  2. The agent searches the whole library to find the papers that match.
  3. At the end, pick the new tag in Zotero’s tag list (bottom left). Only the matching papers are shown.
Models

Use the model you already have

Add an API key, or connect a subscription you already pay for: Codex, Claude Code, Antigravity or GitHub Copilot.

What to look for

  1. Everything is in Zotero Settings → llm-for-zotero.
  2. AI Providers: add an API key for OpenAI, DeepSeek, Gemini, Kimi and others. Each one gets its own card.
  3. Agent: turn on a tool you already pay for, such as Codex, Claude Code or Antigravity. Each has its own on/off switch.
