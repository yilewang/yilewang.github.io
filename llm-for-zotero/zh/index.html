LLM for Zotero

开源的 Zotero Agent 系统

它会阅读你的论文，为每个论断标明出处，并在你需要时直接操作你的文库。使用你已有的模型或订阅即可。

引用回答

每个回答都标明出处

回答会直接引用论文原文。点击引用，PDF 会跳到对应段落并高亮显示。

观看要点

  1. 提问：这篇论文的主要发现是什么？请引用关键证据。
  2. 注意每句话后面的小编号，每个编号都对应论文中的一段原文。
  3. 点击编号，会显示被引用的原话和页码。
  4. PDF 随即跳到这段原文并高亮，方便你亲自核对。
快速提取细节

几秒钟提取关键细节

询问实验对象、任务、记录方法或实验时间线，答案会分条列出，每条都附带引用。

观看要点

  1. 一次提问同时要四样信息：实验动物、任务、记录方法和实验时间线。
  2. 回答把时间线整理成表格：每个时段小鼠在做什么、对应哪一次记录。
  3. 每一条都带有引用编号，任何细节都能追溯到原文。
对比

并排对比多篇论文

输入 @ 从文库中加入任意论文，然后让它生成带引用的对比表格。

观看要点

  1. 输入 @，会弹出你文库中的论文列表。
  2. 选中需要的论文，每篇都会以小标签的形式出现在输入框里。
  3. 回答是一张表格，按研究方法和主要结论把论文逐篇并排对比。
  4. 表格下方有一段简短总结，说明这些论文之间的关系，并附引用。
文库对话

向整个文库提问

Agent 会在你所有的论文中检索和阅读，然后给出真正相关的论文，并附引用。

观看要点

  1. 切换到「文库对话」(Library chat)，就可以针对整个文库提问，而不只是当前打开的论文。
  2. 提问：我的文库里有哪些论文认为表征漂移是有用的，而不只是噪声？
  3. 顶部的「任务进度」(Task progress) 会实时计数：精读了多少篇、找到多少篇、引用了多少篇。
  4. 回答按证据类型（模型研究、理论观点、动物实验）把论文分组，每篇都附引用。
任务进度

看清 Agent 是怎么得出结论的

任务进度完整保留每一次运行：计划、读过的每一篇论文、每篇为什么重要，以及引用的原文。点击「在回答中显示」即可回到对应的论断。

观看要点

  1. 「任务进度」在回答旁边打开，完整展示整个过程。
  2. 「步骤」(Steps) 列出 Agent 要核查的内容，完成的步骤会打勾。
  3. 「In your library」列出用到的每一篇论文。点击任意一篇，可以看到它为什么重要，以及引用的原文。
  4. 点击「在回答中显示」(Show in answer)，会跳回回答，并高亮这篇论文所支持的那句话。
笔记

直接修改笔记

在 Zotero 笔记中选中文字，即可改写、扩写或校对。先查看修改对比，再决定是否替换。

观看要点

  1. 在 Zotero 笔记中选中一段文字，会弹出小菜单：改写、扩写、校对，或在侧边栏提问。
  2. 选择「改写」，修改会以对比形式显示：红色是删去的文字，绿色是新写的文字。
  3. 在你确认之前，笔记不会改变：可以选择替换、插入到下方或放弃。
划词提问

对任意一句话提问

在 PDF 中选中文字，即可解释、释义或翻译，并把回答保存为批注。

观看要点

  1. 在 PDF 中选中一句话，在弹出菜单中选择「Inline Ask」(划词提问)。
  2. 选择解释、释义或翻译，也可以自己输入问题。
  3. 回答直接出现在原文旁边，用通俗的语言说明，不用离开当前页面。
  4. 点击「保存为批注」，回答会和高亮的原文一起保存在 Zotero 中。
技能

使用你自己的技能

把常用流程写成一个技能，用 / 即可运行。比如期刊俱乐部简报、方法核查清单，任何你经常重复的工作。

观看要点

  1. 「技能」(Skills) 面板里保存着常用流程，例如 journal-club-brief、compare-papers 和 analyze-figures。
  2. 在输入框中输入 /，会列出所有操作和技能，选一个即可。
  3. 这里用 journal-club-brief，把一句简单的请求“帮我准备周五的期刊俱乐部”变成一页简报。
  4. 简报每次都按同样的结构：研究问题、实验设计、重点讲解的三张图、局限性，并且全部附引用。
导入

查找并导入相关论文

浏览推荐论文、参考文献和施引文献，勾选需要的论文，一步导入。

观看要点

  1. 输入 /，选择 discover_related。
  2. 面板中列出相关论文，可以在推荐、参考文献、施引文献之间切换，并按相关度、日期或引用数排序。
  3. 勾选需要的论文，点击「Import selected」(导入所选)。
  4. 论文直接进入你的 Zotero 文库，这里一步导入了 5 篇。
整理

用日常语言整理文库

让 Agent 按主题给论文打标签。每一处修改都会与 Zotero 核对，并在回执中列出。

观看要点

  1. 在「文库对话」中用日常语言提出要求：给所有关于嗅觉皮层或梨状皮层表征漂移的论文加上 “olfactory-drift” 标签。
  2. Agent 会检索整个文库，找出符合条件的论文。
  3. 最后在 Zotero 左下角的标签列表中选中这个新标签，只会显示符合条件的论文。
模型

使用你已有的模型

添加 API 密钥，或连接你已经订阅的服务：Codex、Claude Code、Antigravity 或 GitHub Copilot。

观看要点

  1. 所有设置都在 Zotero 设置 → llm-for-zotero 中。
  2. 「AI Providers」页：添加 OpenAI、DeepSeek、Gemini、Kimi 等服务的 API 密钥，每个服务一张卡片。
  3. 「Agent」页：开启你已订阅的工具，如 Codex、Claude Code 或 Antigravity，每个都有独立开关。
最新版本

v3.9.21 有哪些新内容

2026 年 11 月 25 日 发布

Notes become a place to write with AI. Opening a paper’s note no longer replaces the paper’s chat, and selecting text in a note opens a small writing popup. Plain Chat now delivers the paper to providers that used to miss it, and Antigravity gets the full set of Zotero tools. Pictures the agent saves now show inside its answer, and the chat’s scrollbar is no longer hidden behind the composer.
